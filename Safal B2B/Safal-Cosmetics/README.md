# Safal Cosmetics — B2B Website

Safal Cosmetics is a B2B informational website developed to showcase the company's cosmetic manufacturing and filling services. The website provides businesses with information about the company, its services and products, and provides ways for potential clients to get in touch and submit quotation requests.

## 🌐 Website

The website is designed to provide a simple and professional online presence for Safal Cosmetics and help potential business clients learn about the company and its offerings.

## ✨ Features

- 🏢 Company information and overview
- 🧴 Product and service information
- 📋 Quotation request functionality
- 📞 Contact and enquiry options
- 💼 B2B-focused website experience
- 📱 Responsive design for different screen sizes
- 🧭 Easy navigation between different sections
- 📩 Contact forms for business enquiries

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite

## 📂 Website Sections

- **Home** — Introduction to Safal Cosmetics and its offerings
- **About** — Information about the company
- **Products / Services** — Information about the products and services provided
- **Quotation** — Allows potential clients to submit quotation requests
- **Contact** — Provides ways for businesses to get in touch with the company

## 🎯 Project Purpose

The main goal of the website is to provide Safal Cosmetics with a professional digital presence and make it easier for potential B2B clients to understand the company's offerings and contact the business.

The project focuses on presenting business information clearly while providing enquiry and quotation functionality for potential clients.
